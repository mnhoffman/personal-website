Connect to GitHub (one-time)
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it anything (e.g. website editor). Expiration: as long as you like.
  3. Under Repository access, choose Only select repositories and pick personal-website.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Generate it, copy it, and paste it here. It is kept only in this browser (nowhere else), and only ever sent to GitHub.
